Slide 7

Diamond problem in c

The "diamond problem" in C-based Object-Oriented Programming is particularly fascinating because, without language-level features like C++'s virtual base classes, you are forced to solve structural ambiguity by managing raw memory layouts manually. When a derived structure embeds two parent structures that both embed the same grand-parent base structure, C creates two separate instances of that base in memory.

Building OOP Architecture in C

Structs + Function Pointers = Classes
Pillar 1

Encapsulation

Combine data fields and method function pointers within a single contiguous memory block using a struct.

typedef struct Shape { int x, y; // Attributes // Method pointers void (*draw)(struct Shape* self); } Shape;
Pillar 2

Inheritance

Embed the base structure as the first member of the derived structure to share memory layout and allow safe typecasting.

typedef struct { Shape base; // Embedded base int radius; // Extension } Circle; // Safe Upcasting: Shape* s = (Shape*)&myCircle;
